# Data Analytics Portfolio

Personal repository containing end-to-end data analytics projects, SQL query scripts, and business intelligence dashboards.

## Structure

- `/sql` - Data cleaning scripts and analytical queries (PostgreSQL / MySQL)
- `/dashboards` - Power BI and Tableau visualization files

## Projects

### Sales & Operations Performance Analysis
- **Goal:** Analyze multi-channel sales performance and order fulfillment trends to identify revenue drivers and bottlenecks.
- **Tech Stack:** SQL, Excel, Power BI
- **Key Analyses:**
  - Month-over-Month revenue growth and trend analysis using window functions (`LAG`, `LEAD`)
  - Customer segmentation and retention metrics
  - Order delivery delay and fulfillment tracking
